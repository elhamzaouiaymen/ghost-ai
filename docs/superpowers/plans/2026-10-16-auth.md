# Auth Feature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire Clerk into the Next.js app with route protection, auth pages, and a user menu in the editor navbar.

**Architecture:** A `proxy.ts` at the root (Next.js 16's replacement for `middleware.ts`) protects all routes except `/sign-in` and `/sign-up`. The root layout gains `ClerkProvider` with dark theme; `EditorShell` moves to a dedicated `app/editor/layout.tsx` so auth pages render without the editor chrome. The root `/` page redirects based on auth state.

**Tech Stack:** `@clerk/nextjs` v7 (already installed), `@clerk/ui` (to install), Next.js 16 App Router, Tailwind v4 CSS variables for appearance overrides.

## Task 2: Create `proxy.ts` — route protection

**Files:**
- Create: `proxy.ts`

Next.js 16 replaces `middleware.ts` with `proxy.ts`. The export must be named `proxy` (or default). `clerkMiddleware` returns a `NextMiddleware`-compatible function that can be directly assigned.

Public routes are read from `NEXT_PUBLIC_CLERK_SIGN_IN_URL` and `NEXT_PUBLIC_CLERK_SIGN_UP_URL` so they never need to be duplicated.

- [ ] **Step 1: Create `proxy.ts`**

```ts
import { clerkMiddleware, createRouteMatcher } from "@clerk/nextjs/server"

const isPublicRoute = createRouteMatcher([
  process.env.NEXT_PUBLIC_CLERK_SIGN_IN_URL + "(.*)",
  process.env.NEXT_PUBLIC_CLERK_SIGN_UP_URL + "(.*)",
])

export const proxy = clerkMiddleware(async (auth, request) => {
  if (!isPublicRoute(request)) {
    await auth.protect()
  }
})

export const config = {
  matcher: [
    // Skip Next.js internals and static files
    "/((?!_next|[^?]*\\.(?:html?|css|js(?!on)|jpe?g|webp|png|gif|svg|ttf|woff2?|ico|csv|docx?|xlsx?|zip|webmanifest)).*)",
    // Always run for API routes
    "/(api|trpc)(.*)",
  ],
}
```

- [ ] **Step 2: Verify TypeScript compiles**

```bash
npx tsc --noEmit
```

Expected: no errors.

- [ ] **Step 3: Commit**

## Task 3: Add `ClerkProvider` to root layout

**Files:**
- Modify: `app/layout.tsx`

`ClerkProvider` wraps the entire tree. The dark theme base comes from `@clerk/ui/themes`. Appearance `variables` use the app's CSS custom properties (e.g. `var(--bg-base)`) — no hardcoded hex values.

`EditorShell` is removed from the root layout here; it will live in `app/editor/layout.tsx` (Task 4).

- [ ] **Step 1: Update `app/layout.tsx`**

```tsx
import type { Metadata } from "next"
import { Geist, Geist_Mono } from "next/font/google"
import { ClerkProvider } from "@clerk/nextjs"
import { dark } from "@clerk/ui/themes"
import "./globals.css"

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
})

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
})

export const metadata: Metadata = {
  title: "Ghost AI",
  description: "AI-powered system design workspace",
}

export default function RootLayout({ children }: LayoutProps<"/">) {
  return (
    <ClerkProvider
      appearance={{
        baseTheme: dark,
        variables: {
          colorBackground: "var(--bg-base)",
          colorInputBackground: "var(--bg-elevated)",
          colorInputText: "var(--copy-primary)",
          colorText: "var(--copy-primary)",
          colorTextSecondary: "var(--copy-secondary)",
          colorPrimary: "var(--accent-cyan)",
          colorDanger: "var(--state-error)",
          colorSuccess: "var(--state-success)",
          colorWarning: "var(--state-warning)",
          colorNeutral: "var(--bg-elevated)",
          colorShimmer: "var(--bg-elevated)",
        },
      }}
    >
      <html
        lang="en"
        className={`${geistSans.variable} ${geistMono.variable} h-full antialiased`}
      >
        <body className="min-h-full flex flex-col">{children}</body>
      </html>
    </ClerkProvider>
  )
}
```

## Task 5: Update root page with auth redirect

**Files:**
- Modify: `app/page.tsx`

Authenticated users go to `/editor`. Unauthenticated users go to the sign-in URL (read from env so the redirect target matches the registered public route).

- [ ] **Step 1: Update `app/page.tsx`**

```tsx
import { auth } from "@clerk/nextjs/server"
import { redirect } from "next/navigation"

export default async function Home() {
  const { userId } = await auth()
  if (userId) {
    redirect("/editor")
  } else {
    redirect(process.env.NEXT_PUBLIC_CLERK_SIGN_IN_URL!)
  }
}
```

import * as React from "react"
import { PanelLeftClose, PanelLeftOpen } from "lucide-react"
import { UserButton } from "@clerk/nextjs"
import { Button } from "@/components/ui/button"

interface EditorNavbarProps {
  isOpen: boolean
  onToggle: () => void
  toggleRef?: React.RefObject<HTMLButtonElement | null>
}

export function EditorNavbar({ isOpen, onToggle, toggleRef }: EditorNavbarProps) {
  return (
    <header className="flex h-12 shrink-0 items-center border-b border-border-default bg-bg-surface px-3">
      {/* Left section */}
      <div className="flex items-center">
        <Button
          ref={toggleRef}
          variant="ghost"
          size="icon"
          onClick={onToggle}
          aria-label={isOpen ? "Close sidebar" : "Open sidebar"}
          className="text-copy-primary hover:bg-bg-elevated hover:text-copy-primary"
        >
          {isOpen ? (
            <PanelLeftClose className="size-4" />
          ) : (
            <PanelLeftOpen className="size-4" />

      </div>

      <div className="flex flex-1 items-center justify-center" />

      {/* Right section */}
      <div className="flex items-center px-1">
        <UserButton />
      </div>
    </header>
  )
}
